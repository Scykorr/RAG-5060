# Граф связей — краткая инструкция

1. Откройте `http://127.0.0.1:8080/?tab=graph` (или вкладку «Граф связей»).
2. Нажмите **Показать** — загрузятся доступные документы.
3. Если связей нет: **Анализ корпуса** (admin) или укажите UUID в «Центр» → **Анализ центра**.
4. Клик по ребру — тип, origin, score_method, доказательства (фрагменты чанков).
5. Клик по узлу — карточка, таблица связанных, переход в «Документы».
6. Режим «Локальный граф» + глубина 1/2/3 — соседи выбранного документа.
7. **Похожесть (Jaccard) ≠ истинность фактов.** Пока embeddings в Qdrant нулевые, статус `DEGRADED_NO_VECTOR_SEARCH`.
